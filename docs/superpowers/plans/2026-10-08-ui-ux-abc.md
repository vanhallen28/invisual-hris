# Rencana Implementasi — Pembenahan UI/UX A/B/C

> Spec: `docs/superpowers/specs/2026-10-08-ui-ux-abc-design.md`. Tiap tugas diakhiri verifikasi (tsc/lint/build/e2e/tangkapan layar). Tidak ada perubahan logika bisnis.

**Tujuan:** menutup 17 temuan audit secara bertahap (A → B → C), tiap kelompok dikirim sebagai ZIP kumulatif.

**Arsitektur:** perbaikan global lewat token Tailwind v4 di `globals.css`; util murni baru (`lib/tanggalTampil.ts`, `lib/fokus.ts`, `lib/tema.ts`); komponen kecil baru (`components/layout/MenuLainnya.tsx`, `components/Ikon.tsx`); penyuntingan kelas/salinan pada halaman yang disebut spec.

**Teknologi:** Next 16 / React 19 (React Compiler), Tailwind v4, lucide-react 1.x, Playwright (mock PostgREST di scratchpad).

## Batasan global
- Jangan ubah label `CLOCK IN`, `CLOCK OUT`, `Absen Sekarang`, `Tutup Jendela`, `Lihat daftar …`, heading `Log absensi live`, `Butuh persetujuan`, atribut `data-*` yang ada.
- Jangan sentuh `src/components/tracker`, `src/components/chat`, `src/kanvas` kecuali token global.
- Tidak ada `setState` sinkron di `useEffect` (lint React Compiler).
